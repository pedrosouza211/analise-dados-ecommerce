# Análise de Dados de E-commerce

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar consultas SQL, manipulação e análise de dados com Python e Pandas, além da criação de visualizações para apresentação dos resultados.

Utilizando um banco de dados de e-commerce, foram realizadas consultas para analisar diferentes aspectos do negócio, como pedidos, faturamento, produtos, clientes, formas de pagamento e informações operacionais.

Os resultados das consultas foram processados e organizados em arquivos CSV. A partir desses dados, foram desenvolvidos gráficos que posteriormente foram organizados em relatórios visuais, facilitando a interpretação e a apresentação dos resultados.

## Tecnologias utilizadas

- **SQL:** criação de consultas, junções entre tabelas, agrupamentos e cálculos.
- **SQLite:** armazenamento e consulta dos dados.
- **Python:** execução das análises e integração com o banco de dados.
- **Pandas:** exploração, limpeza, manipulação e exportação dos dados.
- **Looker Studio:** desenvolvimento dos gráficos utilizados na elaboração dos relatórios.

## Consultas e análises realizadas

- Clientes por estado.
- Total de pedidos por estado.
- Total de pedidos cancelados por estado.
- Taxa de cancelamento por estado.
- Total de pedidos por mês.
- Faturamento mensal.
- Produtos mais vendidos entre os pedidos entregues.
- Faturamento por categoria.
- Formas de pagamento mais utilizadas.
- Diferença entre preço de venda e custo dos produtos.

## Etapas do projeto

1. Exploração do banco de dados SQLite.
2. Criação de consultas SQL para extrair informações relevantes.
3. Exploração e limpeza dos dados utilizando Pandas.
4. Processamento e organização dos resultados em DataFrames.
5. Exportação dos resultados das consultas para arquivos CSV.
6. Desenvolvimento dos gráficos a partir dos dados processados.
7. Organização dos gráficos e elaboração dos relatórios visuais.

## Estrutura do projeto

- `minhas_consultas.sql`: consultas SQL desenvolvidas durante o projeto.
- `analise_ecommerce.ipynb`: notebook com as etapas de análise em Python.
- `Dados/ecommerce.db`: banco de dados utilizado.
- `Dados/csv/`: arquivos CSV gerados a partir das consultas.
- `Relatórios/`: imagens dos gráficos e relatórios desenvolvidos durante o projeto.
