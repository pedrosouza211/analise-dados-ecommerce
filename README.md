# Análise de Dados de E-commerce

## Sobre o projeto

Este projeto foi desenvolvido para praticar consultas SQL, manipulação de dados com Python e Pandas e representação gráfica dos resultados no Looker Studio.

Utilizando um banco de dados de e-commerce, foram realizadas consultas para analisar pedidos, faturamento, produtos, clientes, formas de pagamento e informações operacionais. Os resultados foram processados e exportados para arquivos CSV, utilizados na criação de gráficos no Looker Studio.

## Tecnologias utilizadas

- **SQL:** consultas, junções entre tabelas, agrupamentos e cálculos.
- **SQLite:** armazenamento e consulta dos dados.
- **Python:** execução das análises e integração com o banco de dados.
- **Pandas:** exploração, limpeza, manipulação e exportação dos dados.
- **Looker Studio:** representação gráfica dos resultados das consultas SQL.

## Consultas e análises realizadas

- Clientes por estado.
- Total de pedidos por estado.
- Total de pedidos cancelados por estado.
- Taxa de cancelamento por estado.
- Total de pedidos por mês.
- Faturamento mensal.
- Produtos mais vendidos entre os pedidos entregues.
- Faturamento por categoria.
- Formas de pagamento mais utilizadas.
- Diferença entre preço de venda e custo dos produtos.

## Etapas do projeto

1. Exploração do banco de dados SQLite.
2. Criação de consultas SQL para análise dos dados.
3. Exploração e limpeza dos dados utilizando Pandas.
4. Processamento dos resultados em DataFrames.
5. Exportação dos resultados para arquivos CSV.
6. Criação de gráficos no Looker Studio.

## Estrutura do projeto

- `minhas_consultas.sql`: consultas SQL desenvolvidas durante o projeto.
- `analise_ecommerce.ipynb`: notebook organizado com as etapas de análise em Python.
- `Dados/ecommerce.db`: banco de dados utilizado.
- `Dados/csv/`: arquivos CSV gerados para as representações gráficas.
